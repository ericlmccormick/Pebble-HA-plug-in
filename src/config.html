Home Assistant Bridge

Configure your Home Assistant server once. Other Pebble apps can request permission to read its entities, send conversation messages, or control services.

Only use this on a trusted private Wi-Fi/LAN. HTTP sends your Home Assistant access token and data without encryption, so anyone able to intercept the network traffic may read or change it. Remote/public HTTP addresses are blocked. Example: http://192.168.1.2:8123 or http://homeassistant.local:8123. Your phone must be connected to that LAN.

Your token is stored privately in the Pebble phone app's secure storage. This page never reads it back.
